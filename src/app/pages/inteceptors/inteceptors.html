Interceptors Works!

Este componente ejecuta dos peticiones HTTP concurrentes al inicializar (ngOnInit) para demostrar el uso de Interceptors.

🛡️

Petición 1: Interceptor Activo

Llama a una ruta inexistente. El http-error-interceptor interceptará el error globalmente.

GET /posts_wrong
⏭️

Petición 2: Interceptor Omitido

Utiliza HttpContext para pasar el token SKIP_ERROR_INTERCEPTOR, gestionando el error localmente en el componente.

GET /pokemon/ditto_wrong
💻 Abre la consola (F12) para revisar cómo se manejaron las respuestas de error de ambas peticiones.
