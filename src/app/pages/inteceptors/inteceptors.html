Interceptors Works!

💡 Los Interceptores HTTP en Angular actúan como un middleware entre tu aplicación y el backend. Permiten inspeccionar y modificar peticiones salientes y respuestas entrantes de manera global. Son extremadamente útiles para tareas como: adjuntar tokens de autenticación (JWT), manejo centralizado de errores globales, mostrar indicadores de carga en toda la app, o añadir cabeceras comunes a todas las peticiones.

A continuación, este componente ejecuta dos peticiones HTTP concurrentes al inicializar (ngOnInit) para demostrar su funcionamiento en la práctica:

🛡️

Petición 1: Interceptor Activo

Llama a una ruta inexistente. El http-error-interceptor interceptará el error globalmente.

GET /posts_wrong
⏭️

Petición 2: Interceptor Omitido

Utiliza HttpContext para pasar el token SKIP_ERROR_INTERCEPTOR, gestionando el error localmente en el componente.

GET /pokemon/ditto_wrong
💻 Abre la consola (F12) para revisar cómo se manejaron las respuestas de error de ambas peticiones.
